# ✈️ Europe Travel Planner (10박 11일 유럽 여행 플래너) 🇮🇹 🇪🇸

이탈리아(로마·피렌체·베네치아)와 스페인(바르셀로나) 10박 11일 여행 일정을 모바일에서 한눈에 확인하고 동선을 시각화할 수 있는 React + Vite 기반의 여행 일정 플래너 웹 애플리케이션입니다.

## ✨ 주요 기능
- **일자별 타임라인 (Day 1 ~ Day 11 & 전체 보기)**:
  - 시간, 소요시간, 카테고리 뱃지(항공, 교통, 숙소, 식당, 카페, 관광, 쇼핑 등)
  - 방문 체크 기능 (체크 시 상태 실시간 보존)
  - 구글 지도 바로가기 버튼 (`mapUrl`) 및 추천 블로그/발권 팁 링크 연동
- **인터랙티브 동선 지도 시각화 (Leaflet 기반)**:
  - 방문 순서가 표기된 번호 핀 마커 및 일자별 이동 동선(Polyline)
  - 마커 클릭 시 장소 정보 및 길찾기 지도앱 바로가기 제공
  - API Key 설정 없이 즉시 동작
- **통합 카테고리 컬러 시스템**:
  - `helpers.js`의 색상 코드와 타임라인 뱃지 및 지도 마커 색상 실시간 연동
- **모바일 최적화 UI**:
  - 스마트폰 화면에 최적화된 반응형 카드 레이아웃 및 부드러운 스크롤 인터랙션

## 🚀 빠른 시작

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 프로덕션 빌드
npm run build
```

## 📂 프로젝트 구조
- `src/components/`: 헤더, DayTabs, 타임라인 리스트, 일정 카드, Leaflet 지도 뷰 등
- `src/data/travelPlan.json`: 10박 11일 상세 일정, 좌표, 소요시간, 구글맵 링크 등 JSON 데이터
- `src/utils/helpers.js`: 카테고리별 테마 색상 설정 및 포맷팅 유틸
